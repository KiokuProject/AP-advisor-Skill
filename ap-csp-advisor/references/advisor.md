# Advisor protocol

Read only for Advisor requests. Select one to three small interventions from
the learner's actual prompt, work, error log, and available study time. Use
[session-protocol.md](session-protocol.md) if the learner wants an interactive
attempt–repair–confirmation–transfer loop.

Separate an observed error from a supported cause hypothesis and a plausible
alternative. A score, wrong option, self-report, or slow time is a provisional
ranking signal, not a diagnosis. Missing work, hint use, independence, deadline,
and time stay unknown. Ask only for evidence that would change the intervention;
otherwise disclose the limitation and offer one useful diagnostic.

Distinguish pseudocode semantics, algorithm/test design, abstraction
explanations, data representation/inference, network mechanisms, computing
impacts, and reading/completeness. Do not prescribe only coding exercises for a
network or social-impact gap. Create-related interventions must follow
[assessment-tasks.md](assessment-tasks.md), especially authorship, permitted
code assistance, and individually completed components.

Rank by evidence strength, impact, useful transfer, and the learner's deadline
and time. Preserve demonstrated strengths with light maintenance. Topic order
is not a prerequisite graph. Each selected task needs:

- **Why now:** the observed evidence, uncertainty, and priority reason.
- **Practice:** a concrete method and bounded amount.
- **Exit:** an observable standard on unseen, independently completed work,
  including the specific error or reasoning demand to check.

Use the boundary file to map the actual content Topic and Computational Thinking
Practice. If only a Practice is established, state that the content Topic is not
established; do not invent it for a neat plan. Topic metadata is not a priority
reason. Do not claim official scoring or whole-course mastery from a diagnosis.

A plan recommends future work; it does not simulate completed attempts. Keep
records session-only, use no identifying details, and do not create files,
calendar events, or external profiles. Honor the requested horizon and fixed
course, Topic, task type, and difficulty.
