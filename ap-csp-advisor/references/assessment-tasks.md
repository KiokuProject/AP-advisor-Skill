# AP CSP assessment and Create support

Read for any exam or Create request. Sources checked 2026-09-08:
[exam page](https://apcentral.collegeboard.org/courses/ap-computer-science-principles/exam),
[student directions](https://apcentral.collegeboard.org/media/pdf/ap-csp-student-task-directions.pdf),
and [plagiarism and AI FAQ](https://apcentral.collegeboard.org/courses/ap-computer-science-principles/course/frequently-asked-questions/questions-about-plagiarism-and-ai).
Recheck them before giving current policy advice; do not use obsolete FAQ
word-count fragments as the current Create format.

## Identify the context

Use the conversation to distinguish ordinary practice, official Create program
development, and individually completed submission or exam components. If that
distinction changes the assistance and is unknown, ask one concise contextual
question while continuing general conceptual help.

- **Ordinary practice:** original examples, debugging, explanations, mock written
  responses, and feedback are available. Label them practice and do not imply
  that a mock response is a final submission or an official scoring guarantee.
- **Official program development:** current policy permits AI as supplementary
  support for coding concepts, code development, and debugging. Keep the student
  actively engaged, identify AI-assisted code for appropriate acknowledgment,
  and check their understanding with a trace, modification, or explanation.
  Do not invent their development process, authorship, or testing evidence.
- **Official video and Personalized Project Reference (PPR):** these must be
  created individually. Explain the general requirements or use a separate
  practice example; do not choose/capture/assemble the student's PPR code
  segments, create their submission video, or attest on their behalf.
- **Actual exam written responses:** these are independently completed on exam
  day using the student-authored PPR. Preparation may use original practice
  prompts; do not produce answers for an exam in progress.

These distinctions come from the official AI FAQ and student directions above.
They do not impose a blanket ban on code assistance. Preserve attribution in
the program-code submission. PPR captures have different rules: no comments or
course content. Do not solve that distinction by erasing attribution everywhere.

## Create requirements for preparation

Teach the learner to check the program's input, output, useful list/data
collection, and a student-developed procedure with parameter(s) that affect
its function. The relevant algorithm in the procedure must contain sequencing,
selection, and iteration; the program must call the procedure. Built-in or
event-handler code alone does not establish a student-developed procedure.
Explain how the actual list and procedure manage complexity, not merely that
their names appear. A preexisting code base needs substantive student work;
cosmetic renaming is not evidence of authorship.

For a practice PPR, distinguish the procedure definition and call, and the code
that stores data in the list and uses that same list. For the official PPR,
provide criteria for the student to apply independently. Students should not
use code they were not actively involved in creating as their PPR evidence.
See the [exam FAQ's authorship guidance](https://apcentral.collegeboard.org/courses/ap-computer-science-principles/course/faq/about-ap-csp-exam).

Do not request accounts, credentials, or submission access. This Skill supports
course learning, not Digital Portfolio administration. For deadlines or file
limits, point to freshly verified official instructions rather than storing a
fixed date or upload specification in practice prompts.

## Match current practice tasks

The recorded format has a 120-minute, 70-question MCQ section worth 70%, plus
Create and a 60-minute exam written-response section together worth 30%.
Create receives at least nine classroom hours. The written-response section
has two questions with four prompts: 1, 2(a), 2(b), and 2(c).
[Official format and categories](https://apcentral.collegeboard.org/courses/ap-computer-science-principles/exam).

| Validator task | Original practice contract |
| --- | --- |
| `mcq-single` | Four options; one correct answer; all necessary code or context supplied. |
| `mcq-reading` | A supplied passage about a computing innovation and a single-select question grounded in it; label invented innovations/data. |
| `mcq-multiple` | Four options; explicitly select two; exactly two correct answers. |
| `written-response` | Name the category below and supply enough program/code context to answer that prompt. One prompt is partial practice, not a full section. |
| `create-practice` | An original development exercise or mock task with a disclosed instructional checklist. This flag cannot certify an official submission. |

The four written-response categories concern program purpose/design/function,
algorithm development, errors/testing, and data/procedural abstraction.
Use actual code and the precise question demand; do not provide memorized prose
that assumes every future prompt asks the same thing. Full-section practice
requires all four prompts and suitable code context for each. Practice 6 is
part of the course but is not an MCQ-assessed Practice. Computing ethics can
still be assessed through an appropriate Practice such as 5.E.

## Review and score honestly

Privately solve the final item; trace every relevant branch/call, check all four
MCQ choices, and enforce AP pseudocode or the specified real-language semantics.
Do not transplant Java indexing or assume an implementation detail absent from
the reference sheet. Original questions and mock checklists are instructional.
Keep answers out of unfinished Coach checks unless explicitly requested.

Official numeric scoring needs the same-year released prompt, applicable
student artifacts, and matching official scoring guidelines. With missing code,
video evidence, or guide, identify what is unjudgeable and give unscored feedback;
never infer a submission-wide score from a short code snippet. Historical
Explore and pre-2024 Create response formats remain historical.
